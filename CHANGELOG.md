# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-05-23

### Added
- 🎨 Four theme support: Matrix Green, Red Team, DFIR Blue, Terminal Amber
- 📁 Metadata extraction with deep file analysis
- 📊 Entropy calculation and visualization
- 🔍 Hash identification (auto-detect algorithm from length)
- ⚙️ Multiple input modes: text, single file, batch processing
- 📤 Export functionality: JSON, TXT, CSV
- 🧠 Session history (last 20 hashes)
- ✅ File verification with auto-algorithm detection
- 🔐 HMAC support for 5 algorithms
- 📱 Full mobile responsiveness
- ♿ WCAG AA accessibility compliance
- 🔑 9 cryptographic algorithms: MD5, SHA-1, SHA-256, SHA-384, SHA-512, SHA3-256, SHA3-512, BLAKE2b, CRC-32

### Changed
- Complete UI redesign with modern dark theme
- Improved algorithm selection UX with visual cards
- Better forensic metadata display
- Enhanced file detection (magic bytes)

### Fixed
- Browser compatibility issues
- Mobile responsiveness edge cases
- Tab navigation accessibility

## [1.0.0] - Initial Release

### Added
- Basic hash generation for common algorithms
- Simple file upload
- Copy-to-clipboard functionality
- Dark theme
